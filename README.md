# CallTrackingMetrics Homebrew Tap

Homebrew tap for CallTrackingMetrics command line tools.

## ctm

The official [CallTrackingMetrics](https://www.calltrackingmetrics.com/) CLI
([calltracking/ctm-cli](https://github.com/calltracking/ctm-cli)):

```sh
brew install calltracking/tap/ctm
```

Upgrades come through `brew upgrade` like everything else. Casks here are
updated automatically on each CLI release; on Linux, use the
[install script](https://github.com/calltracking/ctm-cli#quick-install-macos--linux)
instead.
